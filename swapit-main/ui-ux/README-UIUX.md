# 🎨 SwapIt UI/UX Prototype

This folder contains the **interactive UI/UX prototype** for SwapIt, built in React JSX.

> ⚠️ This is for **design reference only** — the actual project is built in HTML/CSS/JS/PHP.  
> Use this to explore all screens, interactions, and flows before implementing in PHP.

## 🚀 How to Run

### Requirements
- Node.js 18+ ([download](https://nodejs.org))

### Steps

```bash
# 1. Go into this folder
cd ui-ux

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev

# 4. Open in browser
# http://localhost:5173
```

### Demo Login
- Click **"Auto-fill"** on the login page — no credentials needed
