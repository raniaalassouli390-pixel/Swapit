SwapIt — Local Setup on XAMPP

Option A: Setup wizard · Team onboarding guide

Before you start

  • Install XAMPP (PHP 8.1+ and MySQL included).
  • Clone or copy the project into: C:\xampp\htdocs\swapit
  • Folder name should be swapit (lowercase) unless the whole team agrees on another name.
Important: Use http://localhost/swapit/... — not port 8000 or 8080. XAMPP Apache runs on port 80 by default.

1 Start XAMPP

  1. Open XAMPP Control Panel.
  2. Click Start next to Apache.
  3. Click Start next to MySQL.
  4. Both modules should turn green.

If Apache fails to start, another program may be using port 80 (IIS, Skype, etc.). Close that app or change Apache’s port in XAMPP config.

2 Open the setup wizard

In your browser, go to:

http://localhost/swapit/public/setup.php

3 Step 1 — Create config.php

Fill in the form with these values (default XAMPP):

FieldValue
App URLhttp://localhost/swapit (no trailing slash)
DB Hostlocalhost or 127.0.0.1
DB Userroot
DB Passwordleave empty (XAMPP default)
DB Nameswapit

Click the button to create config.php. You should see a success message.

Note: config.php is not in Git. Every team member must create their own copy on their machine.

4 Step 2 — Import the database

On the same setup page, run Step 2 to create the swapit database and import schema + sample data.

Alternatively, use phpMyAdmin (http://localhost/phpmyadmin):

  1. Create database swapit
  2. Import database/schema.sql
  3. Import database/seed.sql

5 Open the website

Use these URLs:

PageURL
Homehttp://localhost/swapit/src/config/pages/home.php
Loginhttp://localhost/swapit/src/config/pages/login.php
Registerhttp://localhost/swapit/src/config/pages/register.php
Shortcuthttp://localhost/swapit/public

6 Test that it works

  • Home page loads without errors
  • Register a new account (no “database error”)
  • Enter the 6-digit verification code on the verify page
  • Log in successfully

Common problems

ProblemSolution
Connection refused / site won’t loadStart Apache; use localhost/swapit not :8000
404 Not FoundProject must be in htdocs\swapit; URL must include /swapit/
Database or config errorsCreate config.php; start MySQL; import SQL files
No verification email in GmailNormal on XAMPP — email doesn’t send locally. Use the dev code on the verify page or check users.verify_token in phpMyAdmin
Broken CSS / imagesAPP_URL in config must match folder name, e.g. http://localhost/swapit

Quick reference

One-line summary:
Put project in C:\xampp\htdocs\swapit → Start Apache + MySQL → Open http://localhost/swapit/public/setup.php → Set App URL to http://localhost/swapit → Import DB → Open home page.
